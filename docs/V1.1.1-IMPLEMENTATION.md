# Disciplina v1.1.1 — Activity Calendar & Interaction Polish

Version 1.1.1, build 6. macOS 14 remains the minimum supported OS.

## Interaction

Tasks, Goals and Activity use full-width sidebar targets. The deletion action bar is shared by all destinations and the fixed menu-bar popover footer. It identifies the deletion, persists until dismissed or undone, and keeps timer feedback separate. Dismissing feedback does not clear the task/milestone deletion stack. Native text Undo/Redo remain separate.

Task appearance optionally combines one of twelve SF Symbols with one of six named tints. Selected rows use native contrasting colors. Quick Capture is unchanged. Current recurring occurrences update their future template; historical occurrences remain independent.

## Recorded activity

A session may contain daily allocations with an identity, session reference, Gregorian day, recording time zone, integer milliseconds and measured/manual/corrected provenance. All allocations and the cumulative session total commit atomically and must sum exactly. The existing coordinator owns timing; presentation ticks do not save or aggregate historical records.

Trusted awake-time intervals split at calendar midnight, including DST. Changed clock/zone mappings, sleep and watchdog gaps cannot invent daily work: uncertain intervals close at the last trusted checkpoint. Historical dates stay fixed after travel. Manual work belongs to its chosen local date. Multi-day correction edits individual recorded days, never a proportionally redistributed total. Unchanged fields preserve millisecond precision.

Legacy sessions remain unallocated. Recovery records their start-day fallback once in the current local time zone. Timer sessions display in a separate legacy subtotal, explicitly describing the missing daily distribution. Legacy manual entries use their chosen work day. Soft deletion retains work; permanent task/session deletion removes it.

## Activity UI

The month grid uses Gregorian dates and localized weekday conventions, with Today/previous/next controls and keyboard day navigation. Day details list sessions, tasks and immutable goal contributions. Weekly Review shows effort by goal and Unassigned, distinct worked tasks, currently completed task/milestone counts, and current active-goal progress. Completion counts are current-state statistics, not an immutable event history. There are no productivity judgments, reminders, scores or streaks.

## Data and delivery

V5 is frozen; V6 adds allocation and appearance metadata. JSON 5 imports formats 1–4 as legacy, with default appearance. Consistent SQLite snapshots, separate migration generations, validation and atomic manifest publication protect existing stores. Unknown imported appearance values normalize to defaults; invalid allocation references, dates, sums and overflow fail validation.

Release gates include domain, timer, appearance, recurrence, migration, JSON, calendar, Undo and native UI regressions. Record actual evidence in VALIDATION.md. Real login, macOS 14, physical sleep/focus, multi-monitor/Spaces and accessibility checks remain pending until exercised on devices. No telemetry, new dependencies or permissions are added.
