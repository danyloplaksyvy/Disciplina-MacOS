# Disciplina 1.0.2

Version 1.0.2, build 3 retains the bundle identifier, macOS 14 deployment target, preferences, and KeyboardShortcuts dependency.

## Layout and presentation

The main window has a 760-point minimum width. Its task list and detail pane have 360- and 300-point minimum widths. A draggable, accessibility-adjustable divider starts at 55% and retains its proportion during the window session. Closing details preserves selection and returns the list to full width. Titles truncate after two lines in rows; details and tooltips retain the complete title.

The status item still owns one transient NSPopover. Its hosting controller and popover delegate configure a floating window that can join Spaces and other applications' full-screen Spaces. Presentation orders only that window forward and requests capture focus on its key-window event, without activating the main window.

## Session corrections

Task details provide Add time, Edit duration, and confirmed permanent session deletion. Editing the running task first checkpoints and pauses it; cancelling never resumes timing. Editing another task does not interrupt the active timer. Session deletion has no Undo; task deletion Undo and native text Undo remain unchanged.

Hours, minutes, and seconds are nonnegative integers; minutes and seconds are bounded to 0–59. Manual additions require positive duration. Existing sessions can be corrected to zero. Unchanged fields preserve original milliseconds; changed input stores whole seconds. Overflow is rejected before commit.

Editing changes only accumulated duration and the edit timestamp, preserving identity, measured timestamps, and end reason. Manually added sessions store the chosen work date in start/end/checkpoint metadata and are explicitly labelled as manual durations, not measured intervals. Session mutations preserve task status, update its modification date, and publish totals only after atomic persistence.

## Migration and backup compatibility

V1 and V2 schemas remain frozen. V3 adds session origin and optional duration-edit timestamp. Old records default to timer origin and no edit timestamp. The existing manifest now records schema version 3. A V2 manifest without a version triggers a consistent SQLite snapshot, migration of a separate copy, complete record validation, and only then atomic manifest publication. The selected source and retained backup stay unchanged. V1 upgrades follow the same staging policy through V2 to V3.

JSON exports use format 2. Format 1 imports remain supported with provenance defaults. Format 2 is not intended for older versions of Disciplina. Preferences are still excluded. Backups and previous store generations are retained without automatic pruning.

## Motion

A structural revision changes only after a successfully committed task operation changes the grouped task IDs. Lists use a 200 ms ease-in-out transition. Timer ticks, checkpoints, failed saves, loading, and store replacement do not request structural animation. Reduce Motion disables movement and animated resizing. Menu bar updates remain immediate.

## Validation

Run `bash scripts/test-core.sh` locally. GitHub Actions builds with Xcode, validates real V1/V2 migrations and failure rollback, and runs native workflows in light and dark appearances. See VALIDATION.md for actual evidence and pending device checks. CI success is not proof of full-screen, multi-monitor, macOS 14, or accessibility acceptance on a physical device.
