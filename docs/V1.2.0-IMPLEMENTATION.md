# Disciplina v1.2.0 — Today & Daily Planning

Version 1.2.0, build 8; macOS 14 minimum. Today is the launch destination, alongside Tasks, Goals and Activity. Tasks remains the full creation-day-grouped library; Command-F always opens its search.

Today shows unfinished work assigned to the local calendar day, earlier unfinished plans grouped newest day first, and a collapsed completed section for today's assignments. Existing-task search excludes deleted/completed tasks. Creating inside Today creates and plans in one transaction; capture and ordinary task creation stay unplanned. Removing a plan never deletes work or stops timing. Completion, reopening and deletion/restoration retain the assigned day.

Tasks hold paired optional plannedDay/planOrder values. PlanningService operates on the shared committed snapshot and commit boundary. Adding/moving appends, reordering changes unfinished slots while retaining completed/deleted positions, and normalization uses deterministic UUID ties. Planning does not change updatedAt, creation dates, recorded effort or recurrence schedules. There is no planning event history or future-date editor.

New recurring occurrences join the actual current day atomically when materialized, retaining their original scheduled recurrence date. Upgrades and enabling recurrence do not plan existing tasks. Local midnight, wake, activation and zone changes update day membership; stored calendar dates never shift. No visual timer tick recomputes planning or search projections.

Schema V6 stays frozen; V7 adds optional planning fields. Staged V1–V6 migration preserves original stores and backups before atomic manifest publication. JSON format 6 includes planning, while formats 1–5 import as unplanned. Invalid paired fields, calendar dates, negative/overflowing order values and stale reorder sets are rejected. Save failure retains the committed plan; a committed change followed by refresh failure uses reload-only recovery.

Today reuses task rows, native list reordering, accessible Move Up/Down, deletion Undo and resizable details with retained drafts/selection. The menu bar and capture interfaces remain unchanged. Compact navigation includes Today. Unavailable storage shows recovery instead of empty counts.
