# Disciplina v1.2.0 — Today & Daily Planning

Version 1.2.0, build 8; macOS 14 minimum. Tasks is the launch destination, alongside Goals and Activity. A native Today / All tasks scope control defaults to Today. All tasks remains the full creation-day-grouped library; Command-F always selects All tasks and focuses search.

Today shows unfinished work assigned to the local calendar day, earlier unfinished plans grouped newest day first, and a collapsed completed section for today's assignments. Existing-task search excludes deleted/completed tasks. Creating inside Today creates and plans in one transaction; capture and ordinary task creation stay unplanned. Removing a plan never deletes work or stops timing. Completion, reopening and deletion/restoration retain the assigned day.

Tasks hold paired optional plannedDay/planOrder values. PlanningService operates on the shared committed snapshot and commit boundary. Adding/moving appends, reordering changes unfinished slots while retaining completed/deleted positions, and normalization uses deterministic UUID ties. Planning does not change updatedAt, creation dates, recorded effort or recurrence schedules. There is no planning event history or future-date editor.

New recurring occurrences join the actual current day atomically when materialized, retaining their original scheduled recurrence date. Upgrades and enabling recurrence do not plan existing tasks. Local midnight, wake, activation and zone changes update day membership; stored calendar dates never shift. No visual timer tick recomputes planning or search projections.

Schema V6 stays frozen; V7 adds optional planning fields. Staged V1–V6 migration preserves original stores and backups before atomic manifest publication. JSON format 6 includes planning, while formats 1–5 import as unplanned. Invalid paired fields, calendar dates, negative/overflowing order values and stale reorder sets are rejected. Save failure retains the committed plan; a committed change followed by refresh failure uses reload-only recovery.

Today reuses task rows, native list reordering, accessible Move Up/Down, deletion Undo and resizable details with retained drafts/selection. The menu bar and capture interfaces remain unchanged. Compact navigation includes Tasks, Goals, and Activity. Today is a scope inside Tasks. Unavailable storage shows recovery instead of empty counts.

Integration: PR #3 merged as 7116764307a9e0443810ef64e9c4f30f41a34aca after checking its head, reviews and passing application/test CI. The only changes after the validated source were validation documentation. Prior release artifacts remain retained.

Search projection trims the query once per projection. Optimized profiling uses an explicit SEARCH_PROFILING build condition plus the existing in-memory UI fixture flags; standard Release excludes fixtures and timing instrumentation. Measurements and remaining device acceptance belong in VALIDATION.md.


## Unified Tasks workspace revision

One creation field, selection, row-draft cache, and detail pane serve both scopes. The two native lists remain mounted in hidden hosting views to retain independent scroll positions without intercepting events. Scope-local search/filters, day expansion, and Today section expansion survive destination changes and window reopening during the session. Earlier plans and Completed today start collapsed; active filters temporarily expand matching sections.

Creating in Today plans atomically; creating in All tasks does not. Add existing task clears Today restrictions and scrolls to the added item without selecting a different detail or requesting editor focus. Ordering is disabled when restrictions hide any unfinished Today row; filters that still show the full order do not prevent reordering. All tasks rows identify Planned today separately from creation dates. Hidden details/drafts remain available, with an outside-scope/filter notice. The current V7 schema and JSON 6 format are unchanged.
